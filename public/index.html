ℹ️ 关于
  • 手动添加节点：在「导入」页填写协议、主机、端口提交即可。
  • 支持的协议：http / https / socks5 / vless（ws+tls），粘贴链接批量导入即可。
  • 出口访问：代理端口（HTTP 38080 / SOCKS5 38081）无需密码，但受 IP 白名单限制 —— 只有「设置 → 🎯 IP 白名单」里登记的来源地址才能访问，其余一律被防火墙拒绝。控制台本身需要密码登录（密码即 server 的 API_TOKEN，见 /opt/node-to-proxy/.env）。
  • 安全：拒绝指向本地出口端口的代理回环；健康检查按协议实测（普通节点 TCP 拨测，vless 节点真实隧道拨测）。
