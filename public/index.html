ℹ️ 关于
  • 手动添加节点：在「导入」页填写协议、主机、端口提交即可。
  • 支持的协议：http / https / socks5 / vless（ws+tls），粘贴链接批量导入即可。
  • 出口鉴权：若服务端设置了 API_TOKEN，代理出口需要
    Proxy-Authorization: Bearer <令牌>（HTTP），
    SOCKS5 使用「用户名=令牌、密码留空」或任何已导入节点的用户名/密码。
  • 安全：拒绝指向本地出口端口的代理回环；健康检查纯 TCP 拨测。
